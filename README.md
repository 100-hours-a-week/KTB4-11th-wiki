# KTB4 11th Team Wiki

개발팀이 같은 맥락에서 빠르게 의사결정하고 실행하기 위한 공유 지식베이스입니다.

## What belongs here

- 제품 방향, 요구사항, 범위, 용어 정의
- 아키텍처와 기술적 의사결정(ADR)
- 회의 결과, 스프린트 계획, 회고
- 운영 절차와 트러블슈팅 기록
- 팀의 **확정된** 합의 사항

> 제안, 가정, 미해결 질문은 확정된 결정과 분리해서 기록합니다. 합의되기 전에는 사실처럼 취급하지 않습니다.

## Decision-record format

새 결정은 `DECISIONS.md`에 아래 정보를 포함합니다.

- 날짜와 상태: **Proposed / Accepted / Superseded**
- 맥락과 해결하려는 문제
- 결정 내용과 근거
- 영향, 담당자, 후속 작업

## Working agreement

- 기본 언어는 한국어입니다.
- 문서 변경은 PR로 검토하고, 확정된 내용만 main에 반영합니다.
- 죠르디는 Discord와 GitHub 이벤트를 통해 논의와 이슈·PR의 맥락을 정리하고, 확정된 합의를 이 저장소에 기록합니다.
